# Airbnb Dataset Cleaning Project

## Overview
Cleaned and transformed an Airbnb dataset using Python and Pandas by handling missing values, removing duplicates, standardizing formats, and preparing the data for analysis

## Skills Demonstrated
- Data Cleaning
- Renaming redundant columns
- Removing Duplicates
- Renaming Columns
- Data Type Conversion
- Data Validation
- Feature Standardization
- Transformation
- Exploratory Data Preparation
- Exporting Cleaned Data

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- VS Code

## Cleaning Process
- Imported the Airbnb dataset
- Explored the dataset structure
- Removing redundant columns
- Removing duplicates
- Identified and handled missing values
- Renamed columns for consistency
- Corrected data types
- Standardized text and categorical values
- Validated data quality 
- Checking for transformation
- Exported the cleaned dataset

## Files
- `Airbnb_Open_Data` – Original dataset
- `Cleaned_Airbnb_Data` – Cleaned dataset
- `Cleaning-Airbnb-Dataset` – Notebook containing the cleaning process

## Objective
The objective of this project is to demonstrate practical data cleaning techniques and create a reliable Airbnb dataset suitable for data analysis and visualization.
